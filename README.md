# 软件工程课程知识库

按上课时间整理的同济软件工程课程笔记，包含结构化笔记、章节范围、课堂时间线、字幕、课件截图和老师口头考点标记。

目前已整理 8 节课，时间为 2026-09-15 至 2026-11-03。2026-10-06 因无视频源跳过。

## 阅读入口

- [章节说明](章节说明.md)
- [老师口头考点索引](老师口头考点索引.md)：每条附时间和转写摘录，已同步嵌入各节笔记。
- [每节课的笔记和资料](raw/软件工程/)

考点标记分为明确会考、经常考、可能考、出题示例和转写待核实。考点依据现有字幕及上下文核查，尚未逐段回听音频。

## 本地浏览

需要 Python 3.12 和 Markdown：

```sh
python -m pip install markdown
python index.py
python -m llmwiki build --out ./site
python -m llmwiki serve --port 8765
```

打开 http://localhost:8765 。

## 目录

- `raw/`：笔记、字幕、时间线、截图与课程清单。
- `wiki/`：知识库页面及配置。
- `llmwiki/`：静态站点构建程序。
- `chapter_ranges.json`、`exam_cues.json`：章节与口头考点的结构化索引。

音视频文件保留在本地，不进入 Git；克隆仓库后可阅读笔记、字幕和截图，视频链接需要补回对应本地录像。`site/` 为生成目录，不提交。

GitHub Pages 工作流仅允许手动触发，需先配置仓库的 Pages 服务。
